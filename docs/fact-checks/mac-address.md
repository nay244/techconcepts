# Fact-check: mac-address

Checked 2026-11-15 by claude-opus-5-5, from a fresh context, against the claim sheet with hash `e828bb1fe24b8a11231560647fd389334469cc3170ea732c3b89983cd1c49cee`. Every source was fetched from its publisher in this run.

Result: 88 ✅, 1 ⚠️, 5 ❌. The lesson does not pass.

The five ❌ share one cause. Each one marks `rfc-894` (Address Mappings) as the defining standard for the broadcast MAC address and what it means. RFC 894 says how IP is carried on Ethernet, and it maps the IP broadcast address onto Ethernet's broadcast address. It does not define that MAC address: it refers to it as Ethernet's existing all-ones address, and Ethernet is defined by the IEEE. In each of the five, the claim itself is true, and another cited source (the IEEE RA EUI guidelines, page 11) states it as well. So with the marker removed (keep the citation, drop "defining standard"), each would be confirmed by two independent sources.
