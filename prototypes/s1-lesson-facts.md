# S1: the Lesson page, as it is built

The scout's fact sheet for the design units of `plan.md` (2026-11-10). Line numbers are those of that day.

S1 fact sheet: Lesson page layout (scout, read-only; no file changed). All paths are repo-relative. CSS line numbers refer to src/lesson/console.css unless another file is named.

ANSWER (summary)
- Desktop (1100px and up): a 2-column grid. Outline is left, 268px. Scene and explanation sit side by side above the log, which spans both columns. Top bar is 68px across the top. Explanation column is clamp(348px, 27vw, 392px).
- The only breakpoints in console.css are 1099px (stacked layout, 761 to 1099 and below), 760px (phone layout, only with JS, `:root.js`), and a reduced-motion query that hides the segment fill.
- data-reading changes the layout only at phone width (18dvh scene instead of 34dvh). On desktop, Learn and Practice do not change the layout.
- The phone layout is fixed-position: top bar, scene, a 3-tab row (Explain, Steps, Log), a scrolling part, and bottom controls.
- The log stacks into rows on phones with data-label captions.
- The lesson's own table (TablePanel) sits under the scene and scrolls with the scene; it has no phone-specific CSS.
- The scene header shows the Network/Sequence switch and title on desktop. At phone width the title is hidden; the switch stays. For OSI Model (one view, no switch), the header is an empty 40px strip.
- og-default.png is 1200x630, 22,237 bytes, generated by scripts/generate-og-image.mjs. It is referenced once, as BaseLayout's default image.
